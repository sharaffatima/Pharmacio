# Pharmacio

Pharmacio is a smart pharmacy management project bringing together its web and mobile applications, backend, and AI/OCR services in one repository.

## Components

- `backend/` — Django REST API and pharmacy workflows.
- `mobile/` — Flutter mobile application.
- `web/` — Flutter web application.
- `services/ocr/` — OCR microservice from `sharafAI-pharmacio-ocr`.
- `services/ai/` — AI microservice from `pharmacio-ai`.

Each component retains its own setup instructions in its README. See the component READMEs for requirements, configuration, and run commands.

## Repository history

Each component was imported from its original repository with Git history preserved. This repository combines the codebases; it does not automatically make their services one deployment or replace their individual configuration.
